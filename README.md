Shop Management System
Introduction

The Shop Management System is a simple C++ project. It is used to manage products in a shop. This program helps the shopkeeper add, display, search, sell, and delete products easily.

Features

This project has the following features:

Add Product: Add a new product by entering its ID, name, price, and quantity.
Display Products: Show all products available in the shop.
Search Product: Search for a product using its ID.
Sell Product: Sell a product and calculate the total bill. The product quantity is also updated.
Delete Product: Remove a product from the shop using its ID.
Exit: Close the program.

How to Run the Program
Open any C++ compiler (such as Code::Blocks, Dev-C++, or Visual Studio Code).
Copy the source code into a new C++ file.
Save the file with the name main.cpp.
Compile and run the program.
Select an option from the menu.
How It Works

When the program starts, it displays a menu with six options. The user can select any option to perform a specific task.

All product information is stored in a vector during program execution.

Purpose of the Project

The main purpose of this project is to understand basic C++ programming concepts and learn how to manage shop products using functions and structures.

Conclusion

The Shop Management System is a simple and useful C++ project. It makes basic shop management easy and helps students understand how C++ works in real-life applications.
